Sistema de Consulta Electoral

Consulta información electoral mediante DNI. Puedes ingresar los números manualmente o procesar una lista desde un archivo Excel.

Ingresar DNI

Opción 1 · Entrada manual

Escribe uno o varios números de DNI. Para consultar varias personas, coloca un DNI diferente en cada línea.

Cada DNI debe contener exactamente 8 dígitos.

Subir archivo Excel

Opción 2 · Procesamiento por archivo

Procesa una lista completa de DNI desde un archivo Excel. El archivo debe contener una columna llamada dni.

Selecciona tu archivo Excel
